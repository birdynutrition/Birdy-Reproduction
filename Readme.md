تطبيق تتبع طيور الكناري

تطبيق مخصص لمربي وهواة طيور الكناري لإدارة ومتابعة دورة حياة الطيور، التزاوج، الإنتاج، والحالة الصحية بكل سهولة.

## ✨ المزايا الرئيسية (Features)
* **سجل الطيور:** إضافة بيانات كل طائر (رقم الحجل، النوع/الطفرة، الجنس، تاريخ الفقس، وصورة الطائر).
* **إدارة التزاوج والأعشاش:** تتبع الأزواج، مواعيد وضع البيض، التخصيب، والفقس.
* **شجرة العائلة (النسب):** معرفة أصول الطائر لتجنب تزاوج الأقارب وتحسين السلالة.
* **المتابعة الصحية:** تسجيل التطعيمات، الفيتامينات، الأدوية، والملاحظات اليومية.
* **التنبيهات والتذكير:** إشعارات لمواعيد الفقس المتوقعة، فطام الفراخ، أو مواعيد تقديم الفيتامينات.
